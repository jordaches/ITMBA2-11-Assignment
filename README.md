GRADE CALCULATOR APP  

Sarah is a teacher at a local high school who wants to simplify the process of calculating and managing students' results. Currently, she spends a significant amount of time manually calculating grades, averaging scores, and generating reports for each student. This manual process not only consumes a lot of her time but also increases the chances of errors. Sarah envisions an Android app that can automate the process of calculating students' results, allowing her to focus more on teaching rather than administrative tasks. The app should be user-friendly, allowing Sarah to input students' scores easily and generate comprehensive reports effortlessly. 

Question: 

As a software developer, you have been tasked with developing an Android app to help Sarah with her requirements. The app should consist of only two files - one XML layout file and one Java file. Below are the details and requirements for each file: 

XML Layout File: 

Create an XML layout file named activity_main.xml. 
Design the layout to include input fields for the following information: 

Student's name 
Scores for three subjects: Mathematics, Science, and English 
A button to calculate the average score and grade for the student 
A TextView to display the calculated average score and grade 
Ensure that the layout is visually appealing and easy to navigate. 
Java File (MainActivity.java): 

Create a Java file named MainActivity.java. 

Implement the logic for the app as follows: 

Retrieve the input values (student's name and scores for three subjects) from the XML layout. 

Calculate the average score of the student based on the scores entered. 

Determine the grade for the student based on the average score: 

A grade of 90% or above: "A" 
A grade of 80% to 89%: "B" 
A grade of 70% to 79%: "C" 
A grade below 70%: "F" 
Display the calculated average score and grade in the designated Text View. 

Ensure that the app handles edge cases gracefully (e.g., invalid input, empty fields).

Word Manipulator: Transform Your Words 

In today's digital age, the ability to manipulate words creatively has become increasingly important. Whether you're composing a tweet, crafting a message, or simply playing with language, having tools that allow you to manipulate words effortlessly can enhance your communication skills. Our new Android app, "Word Manipulator," aims to provide users with a fun and intuitive platform for experimenting with words in unique ways. 

"Word Manipulator" is designed to be a versatile and engaging tool for users who enjoy playing with language. Whether you're a writer looking for inspiration, a student practicing language skill, or simply someone who loves words, this app offers a creative playground where you can experiment with word manipulation techniques. With its user-friendly interface and innovative features, "Word Manipulator" aims to make the process of word manipulation both fun and accessible to everyone 

Imagine you're a software developer tasked with creating a user-friendly Android app that allows users to manipulate words in various ways. The app should provide a simple interface where users can enter three words, manipulate them according to specific rules, and display the results, including an acronym based on the input words.  

Develop the Android app Based on the below Features: 

Input Interface: The app will feature a clean and intuitive interface where users can enter three words. 

Word Manipulation: Once the user submits the input, the app will apply the following manipulations to each word: 

The first word will be converted to uppercase. 
The second word will be converted to lowercase. 
The third word will be reversed. 
Acronym Generation: After manipulating the words, the app will generate an acronym using the first letter of each word. 

Display of Results: Finally, the app will display the original words, the manipulated words, and the generated acronym to the user. 

User Interaction: 

Entering Words: Upon launching the app, users will be greeted with a welcoming screen prompting them to enter three words into designated input fields. 

Manipulation Process: After entering the words, users will trigger the manipulation process by tapping a "Manipulate" button. 

Viewing Results: Once the manipulation is complete, the app will display the original words, the manipulated words, and the generated acronym in a visually appealing format. 

Exploring Options: Users will have the option to reset the input fields and try different combinations of words. 

Example  

Let's consider an example to illustrate how the app works. Suppose a user enters the words "Sun," "Moon," and "Stars." After manipulation, the words will transform as follows: 

Original: Sun, Moon, Stars 

Manipulated: SUN, moon, sratS 

Acronym: Sms
